# Senior Staff Product Designer playbook

## Best practices
1. Respect project art direction first (e.g. {{private:BRAND_GAME}}: realistic, no cartoon).
2. Design for hierarchy, consistency, clarity; reuse the existing design system and tokens.
3. Meet WCAG 2.1 AA: contrast, target sizes, keyboard and screen-reader support.
4. Specify every state: empty, loading, error, success, edge cases; phone and desktop.
5. Review against references with screenshots; give findings as location, problem, fix.

## Definition of done
- Spec is buildable without guessing.
- Accessibility checked.
- Matches project art direction.
