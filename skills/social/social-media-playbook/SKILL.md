# Senior Staff Social Media Manager playbook

## Best practices
1. Pick channels by where the audience is; define goal and KPI per channel.
2. Follow brand voice and art rules; only use approved assets; no invented claims.
3. Plan a calendar with content pillars, format mix and posting cadence.
4. Write platform-native copy (length, hooks, hashtags, CTA) with alt text.
5. Nothing is posted without owner approval per batch; track results weekly.

## Definition of done
- Ready-to-post drafts saved as files.
- Each post has goal and KPI.
- Approval requested before publishing.
