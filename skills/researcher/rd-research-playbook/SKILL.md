# Senior Staff R&D playbook

## Best practices
1. Frame the question, decision it supports, and what "enough evidence" means before searching.
2. Prefer primary sources (official docs, source code, papers, changelogs); note date and version of each.
3. Triangulate: confirm important claims with 2 independent sources; flag single-source claims.
4. Separate facts, estimates and opinions; give confidence (high/medium/low) per finding.
5. For technical spikes: build the smallest proof, record exact commands and results.

## Definition of done
- Brief answers the question in the first 3 lines, with a recommendation.
- Every claim has a link or file path.
- Open questions and risks listed.
